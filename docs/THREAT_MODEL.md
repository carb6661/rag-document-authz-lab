# 风险场景、资产与信任边界

## 0.3版新增检查点

身份解析后、写入前重验会话；成功响应开始前重验原会话、当前对象授权及候选版本。撤销/到期返回401，文档变化返回409，原成功正文被丢弃。会话→文档锁固定顺序，评分和异步发送不占锁。

这缩小旧快照窗口，但不保证检查与网络发送原子化、跨实例撤销或撤回已发送数据。写入已提交再发生撤销，响应可401而数据保留；审计mutation_committed不等于持久事务。全部候选变化都可能导致409，存在保守误拒和重试成本。详见[检查点与边界](REVOCATION_CHECKPOINTS.md)。

## 0.2版引入、仍保留的控制

严格JSON和关键头检查减少解析歧义；64KiB/1024帧/5秒限制约束正文读取，而非整条请求或全局并发。故障审计增加时间、序号及覆盖计数，但仍不能持久化或保证进程崩溃时保全。

关键词检索先授权再评分，不向评分函数传入被拒绝的文档。它不是数据库/向量库的安全下推，当前内存仍持有全部样本；没有外部模型或语义检索。引用只包含合成文档ID与版本。

会话容量有界，签发前清理过期项，支持本进程主体撤销。0.2曾允许评分期间撤销后返回旧快照；0.3已增加上述复核，不能沿用旧版“开始时有效即可”的假设。历史根因见 [技术深挖](TECHNICAL_DEEP_DIVE.md)。

## 资产

RAG候选文档的正文、来源元数据、租户所有权、编辑状态和短期会话。泄漏可能发生在向量化/生成之前；本实验只验证对象API，不验证完整RAG。

## 边界

| 边界 | 风险 | 实施控制 | 残余风险 |
| --- | --- | --- | --- |
| 客户端→身份 | 伪造租户、角色或身份 | 服务端随机会话映射；不读取假身份头 | 会话被盗可冒用；无生产IdP |
| 身份→对象 | 登录后按任意ID访问 | 租户+所有权+角色+动作检查 | 不支持共享、委托、动态属性 |
| 对象→列表 | 单对象安全但列表泄露 | 复用相同读取策略过滤 | 数据库/向量库尚未接入 |
| 更新→存储 | 批量赋值、越权或丢失更新 | 字段白名单、锁内授权及版本检查 | 仅单进程；无数据库事务 |
| 请求→应用 | 大体积、畸形及内容回显 | 64KiB请求限制、字段限长、错误不回显 | 无认证前限流、并发配额或完整网关保护 |
| 应用→审计 | 令牌或正文再次泄漏 | 最小化字段、服务端关联ID、内存上限 | 非持久/不可篡改日志 |
| 缺陷实验→网络 | 误开放故意缺陷版 | CLI仅服务hardened且仅回环；缺陷实验TestClient | 库调用者仍能自行构造unsafe，必须禁止上线 |

没有任意目标URL、凭据尝试、系统文件读取或删除操作。四份文档都是合成样本，所有变更都局限内存。服务显示的短期演示会话也不应上传公开仓库。

404正文统一只减少公开区分，不提供时间侧信道保证。Cache-Control不替代服务端授权，代理与下游缓存仍须正确配置。安装依赖需要网络；固定进程内实验本身不访问外部网络。
