# 验证记录

日期：2026-10-15。环境：Windows / Python 3.12.8；依赖固定在 requirements.lock。

本地 pytest：114 项通过。以下为实际执行结果，不是计划。

- 13组进程内对照共26次请求，预期全部满足；报告逐项精确重放。
- 角色×文档×动作矩阵覆盖5个身份、4份文档、读/写两类动作，并分别检查策略与API。
- 缺陷版同租户越权读、跨租户同名用户读、管理员跨租户读，以及两类越权写均被放行；修复版均返回404。
- 两类越权写在修复版都不改变数据；合法编辑和本租户管理员编辑成功。
- 列表对照为4个→1个文档；该数字仅属于这四份合成样本。
- 令牌到期/撤销、伪造身份头、批量赋值、并发版本、审计最小化和输入边界均有测试。
- pip check未发现依赖冲突。
- live_smoke实际启动回环HTTP，检查自身读取200、他人/跨租户404、匿名401及列表1项，最后关闭服务。

发布前使用 Local Secret Scanner 发现3项疑似匹配，逐项审查为 doclab/api.py 中请求头解析、doclab/security.py 中随机会话生成、tests/test_lab.py 中测试会话签发的变量赋值；没有凭据字面量，不是检出的硬编码密钥。保留这个扫描结论，不以“零匹配”描述。公开身份/文档均为合成数据，报告不包含运行时会话；规则扫描和人工审查仍不是绝对无泄漏保证。

跨平台结果见 [GitHub Actions](https://github.com/carb6661/rag-document-authz-lab/actions/workflows/tests.yml)；不要从本地通过推定其他环境通过。
